HMCL (Hello Minecraft! Launcher) is a free, open-source launcher built on Java, giving it native cross-platform compatibility. In order to set up and create a Quilt instance , follow these steps:

1. Download and install HMCL from [Github](https://github.com/HMCL-dev/HMCL/releases/latest) or [their website](https://hmcl.huangyuhui.net)
2. Open HMCL and log into your Minecraft profile
3. Return to home page, the click **Download** and select the Minecraft version
4. Fill out the **Instance Name** box as required
5. Click **Quilt**, and select the Quilt loader version
6. Click **Install**
7. Click **OK** when the installation is complete, and then click the top navigation bar to return to the home page

Now you can find your new instance in the **All Instance**.

# Installing Mods

To install mods to your HMCL instance, simply follow these steps:

1. Click **All Instance**, find the Quilt instance you installed and click the **Edit Instance** gear button for that entry
2. Click **Mods**, then click **Download** in the panel to search and download the mods, or you can click **Add** to directly import the mod files
3. Ensure you have also added the **Quilted Fabric API/Quilt Standard Libraries** bundle, which you can find [on CurseForge](https://www.curseforge.com/minecraft/mc-mods/qsl) or [on Modrinth](https://modrinth.com/mod/qsl)

Start up your game, and the mods should be available immediately. If you run into any issues, please take a look at the [troubleshooting page](/en/usage/troubleshooting), or [join us on Discord](https://discord.quiltmc.org) to ask for support!
